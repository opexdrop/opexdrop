OpexDrop — версия для GitHub Pages

Файлы сайта:
- index.html — главная страница
- assets/nuts/ — изображения орехов
- .nojekyll — отключает обработку Jekyll

Как опубликовать:
1. Создайте GitHub repository.
2. Загрузите содержимое этой папки в корень repository.
3. Откройте Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: main, Folder: / (root).
6. Нажмите Save.

Важно: index.html должен лежать в корне repository.
